# MLModels

CoreML-модели детекции для модуля `react-native-vision-engine`. Папка
подключена к Xcode-проекту как synchronized group: всё, что лежит здесь,
попадает в бандл, а `.mlpackage` при сборке компилируется в `.mlmodelc`.

| Файл                                | Кто использует                                       |
| ----------------------------------- | ---------------------------------------------------- |
| `container_code_detector.mlpackage` | сканер кодов контейнеров (`features/container-scan`) |
| `plate_detector.mlpackage`          | сканер автономеров (`features/plate-scan`)           |
| `object_detector.mlpackage`         | пример детекции объектов (`features/object-scan`)    |

Имя файла совпадает с `model.name` в конфиге детектора. Модель
опциональна: без неё сканер работает в полнокадровом режиме. После
добавления или замены модели требуется пересборка приложения.

## Формат модели

- вход — RGB-изображение (любой размер, берётся из модели);
- выход — один тензор детекций: классический `[1, 4 + nc, N]`
  (`cx, cy, w, h` + оценки классов, NMS выполняет модуль) или end-to-end
  `[1, N, 6]` (`x1, y1, x2, y2, score, class`); либо модель со встроенным
  NMS (`VNRecognizedObjectObservation`);
- имена классов — в пользовательских метаданных модели (`names`) или в
  метках классификатора; при их отсутствии задаются в `model.labels`.

Классы связываются с доменом по имени, поэтому порядок классов и их
число могут меняться без правок кода. Способ подачи кадра (`resize`),
единицы координат выхода (`boxUnits`) и прочие параметры прогона задаются
конфигом модели в JS (`DetectorModelConfig`).
