# assets

TFLite-модели детекции для модуля `react-native-vision-engine`. Всё
содержимое папки попадает в APK; модуль загружает модель из assets по
имени.

| Файл                             | Кто использует                                       |
| -------------------------------- | ---------------------------------------------------- |
| `container_code_detector.tflite` | сканер кодов контейнеров (`features/container-scan`) |
| `plate_detector.tflite`          | сканер автономеров (`features/plate-scan`)           |
| `object_detector.tflite`         | пример детекции объектов (`features/object-scan`)    |

Имя файла совпадает с `model.name` в конфиге детектора. Модель
опциональна: без неё сканер работает в полнокадровом режиме. После
добавления или замены модели требуется пересборка приложения.

## Формат модели

- вход — RGB `[1, H, W, 3]` или `[1, 3, H, W]`, float32 (значения
  `[0..1]`) либо квантованный uint8/int8;
- выход — один тензор детекций (float32 или квантованный): классический
  `[1, 4 + nc, N]` (`cx, cy, w, h` + оценки классов, NMS выполняет модуль)
  или end-to-end `[1, N, 6]` (`x1, y1, x2, y2, score, class`);
- имена классов — в `metadata.json` (поле `names`) zip-архива, дописанного
  в хвост файла модели; при его отсутствии задаются в `model.labels`.

Классы связываются с доменом по имени, поэтому порядок классов и их
число могут меняться без правок кода. Способ подачи кадра (`resize`),
единицы координат выхода (`boxUnits`), вычислитель (`accelerator`: CPU,
GPU, NNAPI — с откатом на CPU) и число потоков задаются конфигом модели в
JS (`DetectorModelConfig`).
