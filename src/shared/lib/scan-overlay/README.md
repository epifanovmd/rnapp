# scan-overlay

Модель того, что рисует оверлей поверх превью камеры: снимок боксов кадра и чистая
геометрия. Отрисовка (хост оверлея и слои) — в `shared/ui/scan/overlay`.

## Public API

| Экспорт                                         | Что                                                                              |
| ----------------------------------------------- | -------------------------------------------------------------------------------- |
| `IScanRect`                                     | прямоугольник top-left: нормализованный [0..1] или пиксели вью                   |
| `IScanOverlayBox`, `TScanOverlayBoxKind`        | бокс `{ rect, kind, label? }`; `kind`: `text` / `candidate` / `valid` / `region` |
| `IScanOverlaySnapshot`, `EMPTY_SCAN_OVERLAY`    | снимок кадра: боксы, размеры кадра, монотонный `revision`                        |
| `mapRectToView`, `mapOverlayBoxes`, `IViewSize` | нормализованный rect → пиксели вью при `resizeMode="cover"`                      |
| `smoothBoxes`, `ISmoothingResult`               | шаг плавного движения отображаемых рамок к целям скана → `{ boxes, settled }`    |

## Устройство

- Снимок пишет worklet кадра (`publishOverlay` в `shared/lib/ocr-scan`) уже в
  координатах превью; хост оверлея перерисовывает только по смене `revision`.
- `mapOverlayBoxes` выполняется один раз на кадр в хосте: слои получают готовые
  пиксели, вырожденные боксы отбрасываются.
- `smoothBoxes`: цель находит ближайшую отображаемую рамку той же группы и
  интерполируется от неё, несопоставленные появляются сразу. Маппинг и сглаживание
  покрыты тестами.

## Зависимости

- Без внешних зависимостей.
- Потребители: `shared/lib/ocr-scan`, `shared/lib/object-scan`,
  `shared/ui/scan/overlay` (`ScanOverlayHost`, слои рамок, подписей, затемнения).

## Gotcha

- `smoothBoxes` не считается сошедшимся (`settled: false`), пока подпись отображаемой
  рамки отличается от цели — иначе хост оставил бы старую подпись.
