# contracts

Место для контрактов, через которые слайс пользуется возможностью соседнего слайса,
не импортируя его (слайсы одного слоя друг друга не видят).

## Public API

| Экспорт             | Что                                                                              |
| ------------------- | -------------------------------------------------------------------------------- |
| `IAuthSessionGuard` | токен + контракт текущей auth-сессии: `isCurrentSession(sessionId)`, `signOut()` |

## Устройство

- Один файл на контракт: `<name>.contract.ts` — интерфейс и токен
  `createInjectDecorator` с тем же именем.
- Реализацию биндит слайс-владелец в своём `<slice>.module.ts`: `IAuthSessionGuard` —
  `entities/auth` (`AuthSessionGuard`).

## Зависимости

- `@shared/lib/di` — токен.
- Потребители `IAuthSessionGuard`: `entities/user` (стор сессий — выход при завершении
  текущей сессии), `pages/stack` (экран сессий).

## Gotcha

- Без загруженного модуля владельца `getInstance()`/`useInstance()` бросают ошибку
  контейнера — контракт работает только в собранном `app.module.ts` или в тесте с
  явным биндингом.
