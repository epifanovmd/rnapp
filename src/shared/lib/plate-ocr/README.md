# plate-ocr

Предметная логика распознавания номера РФ формата `L DDD LL RR(R)` поверх строк OCR.
Конфиг сканера (модель, подтверждение) — в `features/plate-scan`.

## Public API

| Экспорт                                | Что                                                      |
| -------------------------------------- | -------------------------------------------------------- |
| `extractPlateCandidates(observations)` | кандидаты номера из OCR-областей (worklet)               |
| `parsePlate(value)`                    | `"A123BC77"` → `{ base, region }`; `null` — длина не 8–9 |
| `formatPlate(value)`                   | `"A123BC77"` → `"А 123 ВС 77"` (кириллица ГОСТ)          |
| `IPlateCandidate`, `IPlateParts`       | типы                                                     |

## Устройство

- Каноническое значение — латиница, как читает OCR: буквы номера — только
  `ABEKMHOPCTYX` (кириллица, совпадающая с латиницей).
- Кандидаты: окна 8–9 символов из одиночных областей и пар соседних (основная часть и
  регион печатаются раздельно). Похожие символы подменяются по позиции (буква ↔ цифра);
  регион — `01`…`99` или трёхзначный не с нуля.
- Контрольной цифры у номера нет, поэтому подстановки детерминированные и прошедший
  формат кандидат сразу валиден.
