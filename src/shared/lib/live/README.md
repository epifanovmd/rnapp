# live

Снимок сущности с сервера при открытии, дальше — события сокета; опционально скользящее
окно точек для графика. Тик сокета перерисовывает только observer-компоненты, читающие
`live`/`points`, а не держателя модели.

## Public API

| Экспорт                                                                       | Что                                                                     |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `useLiveModel(options)`                                                       | `ILiveModel { live, points, reload }` — стабильный объект с MobX-полями |
| `IUseLiveModelOptions`, `ILiveWindowOptions`, `ILiveLoadResult`, `ILiveModel` | контракты хука                                                          |
| `pushLivePoint`, `mergeLivePoints`, `trimLivePoints`                          | чистые операции окна                                                    |
| `ILivePoint`, `ILiveWindowLimits`                                             | точка (`ts`, мс) и границы окна (`maxPoints`, `windowMs`)               |

## Устройство

- Опции: `id` (`null` — не загружать и не слушать), `event`, `select(payload, id)` —
  снимок `id` из события, `load(id)` — текущий снимок в форме ответа API-клиента,
  `window` — `toPoint`, `load` истории, границы.
- Состояние принадлежит `id`: при его смене прежние данные не показываются, ответ
  загрузки для устаревшего `id` отбрасывается.
- `enabled` (по умолчанию `true`) — например `useIsFocused()`: выключено — тики не
  обрабатываются; включение перечитывает снимок и историю, потому что события за паузу
  потеряны.
- Окно: точка не новее последней отбрасывается; история с сервера — основа, из живых
  точек остаются только более новые.

## Зависимости

- `shared/lib/socket` (`useSocketEvent`), `shared/lib/hooks` (`useLatestRef`), `mobx`.
- Потребителей в `src` сейчас нет.

## Gotcha

- `live` и `points` — `observable.ref`: массив только заменяется, читать их нужно в
  `observer`-компоненте.
