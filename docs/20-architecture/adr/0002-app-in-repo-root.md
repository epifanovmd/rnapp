# ADR-0002: приложение в корне репозитория

- Статус: принято
- Дата: 2026-11-02

## Контекст

Репозиторий был шаблоном для `react-native init --template`: приложение лежало в
`template/`, корень занимали файлы утилиты генерации. Из-за этого git-хуки ставились
обходным раннером через `core.hooksPath`, команды и пути в документации шли с префиксом
`template/`, а инструкции агента и общие документы жили в разных местах.

## Решение

- Содержимое `template/` перенесено в корень с сохранением истории; файлы утилиты
  генерации удалены.
- Lefthook ставится стандартно (`prepare: lefthook install`).
- `Gemfile.lock` и `ios/Podfile.lock` фиксируются, как у обычного приложения.
- Пути к соседним репозиториям (`anchor-list`, спецификация API) — относительно корня.

## Последствия

- Генерация новых проектов через `react-native init --template` больше не
  поддерживается; новый проект — копия репозитория.
- Система знаний лежит в корне вместе с приложением.
