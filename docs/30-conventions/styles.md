# Стили и UI

- Используются UI-кит и принятый механизм темы; новый базовый компонент — в
  `shared/ui`, а не локальная копия.
- Тема и отступы берутся из механизма темы, а не из литералов по месту.
- Статические стили объявляются заранее и не создаются заново на каждом render.
- Динамические значения добавляются отдельным элементом массива styles, а не слиянием
  объектов в render.
- Platform-specific файл (`.ios` / `.android`) — только когда реализация действительно
  различается; публичный API остаётся единым.
- Naming, требуемый платформой или codegen, не меняется в угоду общим правилам.

Конкретика UI-кита — [shared/ui](../../src/shared/ui/README.md), тема —
[shared/lib/theme](../../src/shared/lib/theme/README.md).
