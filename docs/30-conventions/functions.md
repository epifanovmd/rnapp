# Функции

## Только стрелочные

- Все функции — стрелочные: `const fn = (a: A): B => {}`,
  `export const Component = (props: IProps) => {}`, в `.tsx` дженерик —
  `const f = async <T,>(x: T) => {}`.
- `function`-объявления и выражения запрещены — для компонентов, хуков, хелперов,
  type guards, фабрик, callback-ов и worklets (директива `"worklet"` остаётся первой
  строкой тела). Проверяется `func-style`, `prefer-arrow-callback`.
- Методы классов остаются методами.
- У `const` нет hoisting: хелпер объявляется выше первого использования.
- Хук, присваиваемый в свойство объекта или возвращаемый из фабрики, сначала
  объявляется константой `useX`, чтобы правила хуков видели имя.
- Исключение — файлы деклараций типов и codegen-спеки нативных модулей, чей синтаксис
  диктует генератор.

## Устройство функции

- одна связная операция на одном уровне абстракции;
- зависимости — явно, параметрами;
- предсказуемый возвращаемый тип;
- входные данные не мутируются без контракта;
- I/O не прячется под именем вычисления; вычисление — чистая функция.

Несколько boolean-параметров скрывают смысл — объект options:

```ts
send(message, true, false); // ❌
send(message, { silent: true, retry: false }); // ✅
```

Если options выбирают разные алгоритмы — отдельные функции или Strategy.
