# React-хуки

- Хуки вызываются только на верхнем уровне компонента или другого хука; имя
  начинается с `use`.
- Dependency array отражает фактические зависимости и семантику эффекта.
- Dependency array не меняется механически ради линтера без проверки изменения
  поведения.
- Стабильный callback, которому нужны свежие значения, — принятый в проекте
  latest-ref / use-event паттерн.
- Mount-only эффект действительно mount-only; почему зависимости стабильны — видно из
  структуры кода.
- Новые отключения `react-hooks/exhaustive-deps` не добавляются без отдельного
  архитектурного решения. Существующие точечные suppressions не расширяются и
  образцом не являются.
- Custom hook возвращает минимальный контракт. Навигация, UI и инфраструктура не
  смешиваются с model-логикой без необходимости.
- Derived state вычисляется из источника, а не синхронизируется отдельным эффектом.
