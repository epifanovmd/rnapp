# Формы

- Форма описывается декларативно: схема валидации отдельно (`model/validation.ts`),
  компонент — только отображение и wiring. Стек — React Hook Form + Zod через
  `zodResolver`.
- Валидация, общая для нескольких сценариев одного домена, живёт в соответствующей
  сущности, а не дублируется по features.
- Правила валидации — model-слой; сообщения об ошибках принадлежат UI-слою.
- Стандартные сообщения — на языке интерфейса; пустое необязательное поле — допустимое
  значение.
