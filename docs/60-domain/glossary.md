# Глоссарий

| Термин             | Значение                                                                                       |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| сессия             | пара access/refresh токенов одного входа; у пользователя их несколько (устройства)             |
| 2FA, второй фактор | второй пароль после основного                                                                  |
| биометрия          | вход по Face ID / отпечатку: сохранённые учётные данные открываются датчиком устройства        |
| guard-группа       | группа экранов навигатора с условием `if` (вошёл / не вошёл); смена состояния переключает стек |
| комната            | серверная подписка Socket.IO на поток событий                                                  |
| холдер             | объект асинхронного состояния запроса (`shared/lib/holders`)                                   |
| VM-хук             | `use<Name>VM` — хук сценария экрана/фичи, отдаёт данные и действия UI                          |
| панель (bar)       | скрываемая при скролле шапка или таб-бар (`shared/lib/bars`)                                   |
| телеметрия скролла | единственный владелец `onScroll`: смещение, направление, фазы жеста (`shared/lib/scroll`)      |
| конвейер кадра     | worklet-обработка кадра камеры: детекция → отбор регионов → OCR (`shared/lib/ocr-scan`)        |
| регион             | область кадра, найденная детектором и подписанная классом модели                               |
| плейграунд         | демо-экраны UI-кита (`pages/stack/components`)                                                 |
| слайс, сегмент     | единицы FSD — [architecture/fsd-layers](../20-architecture/fsd-layers.md)                      |
